# Code of Conduct

The Libre VMM project adopts the [Contributor Covenant, version 2.1][cc21]
as its community code of conduct. The full text is the authoritative
version; this file's role is to point you to it and identify the contact
channel.

## Adoption

By contributing to this project — whether code, documentation, issues,
discussions, or other channels — you agree to abide by the terms of the
Contributor Covenant 2.1 as published by the Contributor Covenant
organization at the URL below.

The canonical text governs in case of any discrepancy with summaries.

[cc21]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Scope

This Code of Conduct applies to all project spaces, including:

- The Git repository at https://github.com/LucentOpenSoftware/libre-vmm
- Issue trackers, pull requests, and discussions
- Release announcements, project chat channels, and project social media
- Community events organized under the project's name
- Any space where you are representing the project publicly

## Reporting

A dedicated reporting channel will be established before the first
public release. In the interim, community members who need to raise a
concern privately can do so by:

- Opening a confidential discussion via the repository's [Security tab][sec]
  using GitHub's private reporting feature, or
- Mentioning a maintainer in a draft pull request marked as private

[sec]: https://github.com/LucentOpenSoftware/libre-vmm/security

Reports are handled in confidence by the maintainer team and will
receive an initial response within the timeline described in the
Contributor Covenant.

## Enforcement

Enforcement follows the four-tier guidance in the Contributor Covenant
2.1 (Correction, Warning, Temporary Ban, Permanent Ban). The maintainers
are responsible for clarifying standards and applying these guidelines
fairly. Decisions may be appealed via the same channels described above.
